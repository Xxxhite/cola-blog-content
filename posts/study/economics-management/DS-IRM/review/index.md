## 第一章 信息资源管理概述

1. **信息资源管理**是指管理者为达到预定目标，运用现代化的管理手段和方法，研究信息资源在经济活动和其他活动中的利用规律，并依据这些规律对信息资源进行组织、规划、协调、配置和控制的活动。
2. 信息资源的一般特征包括：作为生产要素的人类需求性、稀缺性和使用方向的可选择性。其特殊性包括：共享性、时效性、非同一性、驾驭性、累积性与再生性。
3. 信息的主要功能包括经济功能、管理与协调功能、选择和决策功能，以及研究与开发功能。
4. 在社会组织的微观层面，信息资源管理活动主要体现为过程管理；在社会组织体系的中观层面，主要体现为网络管理；在国家和政府的宏观层面，主要体现为以政策法规为主导的调节管理。

## 第二章 信息资源过程管理

1. 信息资源过程管理包括信息采集、信息组织加工、信息存储与检索，以及信息服务四个部分。
2. **直接评价法**是按照对信息源的一般要求制定标准或指标，从不同角度和侧面对信息源的价值进行评分。这种方法简单易行，但带有一定的主观色彩。
3. **间接评价法**是通过信息用户评价信息源。通常采用调查表等方式调查用户对信息源的需求和利用情况，再由信息工作者对数据进行统计分析和对比，从而评价信息源的价值。这种方法需要信息用户的密切配合，工作量较大，但评价结果较为客观。

## 第三章 信息资源管理法规

1. **莫尔矩阵模型**从“作用层次”和“政策要素”两个维度分析信息政策。模型包含产业、组织和社会三个层次，以及信息技术、信息市场、信息管理、人力资源和法律法规五个政策要素。

   | 维度 | 构成 |
   | :--- | :--- |
   | 作用层次 | 产业层次、组织层次、社会层次 |
   | 政策要素 | 信息技术、信息市场、信息管理、人力资源、法律法规 |

   **三个作用层次**

   | 层次 | 主要内容 |
   | :--- | :--- |
   | 产业层次 | 主要考虑本国经济中信息部门的发展问题，研究信息政策如何规范信息服务部门的发展，使信息产业、信息产品和服务市场健康发展。 |
   | 组织层次 | 通过对信息资源进行管理和处理，确保组织能够有效利用信息资源，提高生产力、效率和竞争地位。 |
   | 社会层次 | 主要考虑个人和社会团体的信息需求与供给，研究人们利用信息的方式，确保公民能够有效利用社会、政治和经济信息，并获取社会提供的利益。 |

   **五个政策要素**

   | 政策要素 | 主要内容 |
   | :--- | :--- |
   | 信息技术 | 确保信息在正确的时间，以最低的成本，通过正确的渠道传递给正确的用户。 |
   | 信息市场 | 建立有效的市场机制，刺激信息的供给和需求。 |
   | 信息管理 | 确保信息资源得到有效组织、开发和利用，提升信息管理活动的整体效能。 |
   | 人力资源 | 通过教育和培训提高公民的信息意识，促使人们掌握信息处理和利用技能，把握信息密集型社会带来的各种机会。 |
   | 法律法规 | 在权利和责任之间达成平衡，以适应信息技术迅速发展所带来的需求变化。 |
2. **知识产权**是指自然人或法人通过脑力劳动，在科学技术、文化艺术等领域创造精神财富，并在一定地域和期限内依法确认和享有的权利。

## 第四章 网络信息与大数据资源配置

1. **数据分析**是指对海量、类型多样、增长快速且内容真实的数据进行分析，从中找出能够帮助决策的隐藏模式、未知的相关关系以及其他有用信息的过程。
2. **数据挖掘**是知识发现的一个步骤，指通过算法从大数据中挖掘隐藏于其中的有价值信息的过程。
3. 大数据管理总体框架可以概括为“一个机制、两个体系和三个平台”。大数据管理工作机制包括数据共享与开放、工作协同、大数据科学决策、精准监管和公共服务等机制；两个体系分别涉及大数据交换、共享、一致、整合和应用的安全保障与标准化工作；三个平台承担大数据基础设施、网络资源、计算资源、存储资源和安全资源的集约化管理，以及系统运维、数据采集、处理、分析和应用等工作。
4. 大数据质量的一级特征指标包括功能性指标、性能性指标、易用性指标、效率性指标、挖掘性指标、维护性指标和推广性指标。

## 第五章 信息资源管理技术及其资源化

1. **信息安全**是指保护信息网络的硬件、软件及系统中的数据，使其不因偶然或恶意原因遭到破坏、篡改或泄露，确保系统连续、可靠、正常运行，保证信息服务不中断。信息安全的目标包括保密性、完整性、可用性、可控性和不可否认性。
2. 区块链的主要特征包括去中心化、开放性、独立性、安全性和匿名性。
3. **数据中心**是基于 Internet 网络的基础设施，包括服务器、网络设备、存储设备以及管理软件等，可用于数据存储、处理、服务和管理。数据中心智能化是指通过应用人工智能技术提高数据中心的运营效率，降低运营风险和成本，从而提升整体管理水平和持续发展能力。
4. 狭义的计算资源指计算机程序运行时所需的 CPU 资源、内存资源、硬盘资源和网络资源；广义的计算资源还包括硬件、软件、网络、数据以及其他相关支撑环境，甚至包括操作人员。

## 第六章 信息资源标准化管理

1. 实施标准化的基本原理包括简化原理、统一原理、协调原理和最优化原理。
2. 标准化的管理原理包括系统效应原理、结构化原理、有序发展原理和反馈控制原理。
3. **标准化**是为了在一定范围内获得最佳秩序，对实际的或潜在的问题制定共同的、重复使用的规则的活动。
4. **标准化空间**是由专业、内容和级别三个维度组合而成的空间。标准化空间的 `x` 轴代表标准化活动的各个专业领域，`y` 轴代表标准化的内容，`z` 轴代表标准化的级别。

## 第七章 信息系统资源管理

1. **招投标**是指采购人在大宗商品采购或大型建设项目外包中，不采用一般交易流程，而是事先提出货物、工程或服务采购的条件和要求，邀请多个投标商参加投标，并按照规定程序从中选择交易对象的一种市场交易行为。
2. **信息系统监理**是指聘请信息系统甲方和乙方以外、具有监理资质的第三方，对信息系统建设行为进行监控、督导和评价，并采取相应的管理措施。
3. **管理信息系统**是由人、计算机等组成的，能够进行管理信息收集、传递、存储、加工、维护和使用的系统。其特点包括面向管理决策、综合性、人机系统、现代管理方法和手段相结合，以及多学科交叉的边缘科学属性。
4. 信息系统实施的三种策略及其优缺点如下：
    - 联合开发策略：联合开发是指组织的 IT 人员和开发公司的技术人员一起工作，完成开发任务。优点是比较节约资金，可以培养、增强企业的技术力量，便于系统维护工作。缺点是双方在合作中易出现扯皮现象。
    - 应用软件包策略：通过购买应用软件包建设本组织的信息系统。优点是具有标准、统一的工作程序，能够减少开发时间和费用，并提供持续的系统维护、支持和先进的工作流程。缺点是软件方案可能不完全适配组织需求，定制会导致系统建设费用增加。
    - 外包策略：雇佣专门从事相关服务的组织，将组织的计算中心操作、远程通信网络或应用开发转交给外部供应商。优点是降低成本，获得标准流程的服务支持，减少对技术人员的需求，降低信息系统建设风险。缺点是组织可能失去对信息系统，甚至对关键资源的控制。
5. 信息系统评价的四个阶段包括组织的信息系统环境分析、信息系统基础设施评价、信息系统接口评价和信息系统活动评价。
6. 信息系统监理还应保证信息系统工程建设行为符合国家法律法规和有关政策，制止建设行为的随意性和盲目性，促使建设质量、进度、造价和计划目标得以实现，确保建设行为的合法性、科学性、合理性和经济性。
