## 一、文字陷阱：判断题语气词

科目一判断题最高频的失分点，就藏在几个关键的语气词里。

### 1.1 语气词判断规律

| 语气词类型 | 示例 | 判断倾向 |
|-----------|------|---------|
| 「可以」「允许」「随意」「不必」 | 「可以不系安全带」 | 多为**错误**（法规题一般不允许随意）|
| 「应当」「必须」「不得」「禁止」 | 「必须减速慢行」 | 多为**正确** |
| 「只要…就」「不管…都」 | 「只要减速就可以通过」 | 绝对化表述，多为**错误** |

### 1.2 三大易混概念

**「停车」vs「临时停车」vs「停放」**

三种含义不同，对应的扣分与罚款档次也不同，切勿混用。

**「饮酒驾车」vs「醉酒驾车」**

| 状态 | 处罚 |
|------|------|
| 饮酒驾车 | 记 12 分 + 暂扣驾驶证 |
| 醉酒驾车 | 吊销驾驶证 + 追究刑事责任 |

:::warning[判断题红线]
造成轻伤以上 / 死亡后逃逸（不构成犯罪）= 12 分；无伤亡属轻微档次，两者天壤之别，绝对不能混淆。
:::

**核心心法**：法规类判断题，越「绝对、随意」越错；越「谨慎、让行」越对。

## 二、数字类陷阱：限速 / 能见度 / 距离

### 2.1 一般道路限速（最高）

| 道路条件 | 最高限速 |
|---------|---------|
| 没有中心线，城市道路 | 30 km/h |
| 没有中心线，公路 | 40 km/h |
| 有中心线，城市道路 | 50 km/h |
| 有中心线，公路 | 70 km/h |

### 2.2 必须降速到 30 km/h 的情形（多选题高频）

- 转弯、掉头、下陡坡
- 进出非机动车道
- 通过铁路道口
- 窄弯 / 窄路 / 窄桥
- 能见度低于 50 米
- 牵引故障机动车

### 2.3 高速公路车道最低车速

| 车道数 | 最左侧车道 | 中间车道 | 最右侧车道 |
|-------|----------|---------|---------|
| 同向 2 车道 | 100 km/h | — | 60 km/h |
| 同向 3 车道 | 110 km/h | 90 km/h | 60 km/h |

### 2.4 能见度 / 速度 / 车距「三档表」

:::note[经典考点]
很多人记不清「50 米」对应的是能见度还是车距，其实**能见度 < 50 m 时，速度才降至 20 km/h**。
:::

| 能见度 | 最高车速 | 最小车距 |
|-------|---------|---------|
| 200 m ≥ 能见度 > 100 m | 60 km/h | 100 m |
| 100 m ≥ 能见度 > 50 m | 40 km/h | 50 m |
| 能见度 < 50 m | 20 km/h | 尽快驶离高速 |

### 2.5 禁止停车距离

| 地点 | 禁止停车范围 |
|------|------------|
| 交叉路口、铁路道口、窄路、桥梁、陡坡、隧道 | 前后各 **50 米**内不得停车 |
| 公交站台、消防栓、加油站、医院门前 | 前后各 **30 米**内不得停车 |

## 三、标志标线「孪生兄弟」

这些标志长相相似，极容易张冠李戴。

| 标志 A | 标志 B | 区分要点 |
|--------|--------|---------|
| 禁止驶入（红底白横杠） | 禁止通行（白底红圈，空心） | 形状和底色不同 |
| 停车让行（八角形「停」） | 减速让行（倒三角「慢」） | 形状完全不同 |
| 单行路（蓝色长方形） | 直行（蓝色圆形） | 形状区分 |
| 禁止停车（蓝底红圈 + 红叉） | 禁止长时间停车（蓝底红圈 + 单斜杠） | 红叉 vs 单斜杠 |

**左侧 / 右侧 / 两侧通行**：看线条顶端朝向——朝左 = 左侧行，朝右 = 右侧行，∧ 形 = 两侧通行。

**注意行人 vs 人行横道**：黄底 = 警告注意；蓝底 = 指示横道。

:::caution[特例陷阱]
「禁止停车」和「禁止长时间停车」虽然底色是**蓝色**，但它们是**禁令标志**（不是指示标志），判断时认准「红圈」，不要被蓝底误导。
:::

## 四、交警手势：8 种口诀速记

**核心规律**：「伸哪只手」决定「哪个方向」，「手臂摆动」决定「动作」。

| 手势 | 动作要领 |
|------|---------|
| 停止 | 左臂向前上方直伸，掌心向前 |
| 直行 | 两臂向左右两侧平伸，右臂随后向左摆动 |
| 左转弯 | 右臂前伸 + 左臂摆动 |
| 右转弯 | 左臂前伸 + 右臂摆动 |
| 左转弯待转 | 左臂向左下方平伸，掌心向下 |
| 变道 | 右臂前平伸，掌心向左，水平摆动 |
| 减速慢行 | 右臂向右前方平伸，掌心向下，下压 |
| 靠边停车 | 左臂高举（停止）+ 右臂摆动 |

:::tip[三个经典易错点]
1. **左转弯 = 伸右臂，右转弯 = 伸左臂**（正好相反，最易错）
2. **减速慢行 = 下压**；靠边停车 = 高举 + 摆动，别搞混
3. **交警手势 > 信号灯**，同时出现时以交警指挥为准
:::

## 五、灯光使用：会车、跟车、特殊场景

| 场景 | 使用灯光 |
|------|---------|
| 照明良好、隧道内 | 近光灯 |
| 照明不良、无对向来车 | 远光灯 |
| 夜间超车、窄弯 / 坡道 / 拱桥 / 人行横道 | 交替远近光 |
| 雾天 | 雾灯 + 近光 + 示廓灯 + 前后位灯 |
| 故障 / 临时停车、能见度 < 100 m | 危险报警闪光灯 |
| 起步、左转弯、掉头、超车、变道、驶入高速 | 左转向灯 |
| 右转、靠边停车、超车后回原车道、驶离高速 | 右转向灯 |

:::warning[超车灯光顺序]
超车时：**先打左转向灯（提示）→ 超车 → 再打右转向灯（回道）**，不是一直打左灯。
:::

## 六、记分 / 罚款 / 处罚档次（2022 新规）

### 6.1 扣分档次速查

| 分值 | 对应违法行为 |
|------|------------|
| **12 分** | 饮酒驾车；造成轻伤以上 / 死亡事故逃逸（不构成犯罪）；伪造变造牌证；驾驶与准驾车型不符；高速逆行 / 掉头；代替他人记分牟利 |
| **9 分** | 高速 / 快速路违法停车；7 座以上超载 50%～100% |
| **6 分** | 闯红灯；高速 / 快速路超速 20%～50%；驾驶证暂扣期间驾车 |
| **3 分** | 不按规定超车 / 让行；高速 / 快速路不按规定车道行驶；不避让校车 |
| **1 分** | 不按规定使用灯光；违反禁令标志标线；未系安全带（有道路） |

### 6.2 罚款易混点

| 违法行为 | 处罚 |
|---------|------|
| 饮酒驾车 | 记 12 分 + 暂扣 6 个月 + 罚款 1000～2000 元 |
| 醉酒驾车 | 吊销驾驶证，5 年内不得重考 + 追究刑事责任 |
| 无证驾驶 | 罚款 200～2000 元，可处 15 日以下拘留 |

## 七、仪表指示灯：看图识别速查

| 指示灯图案 | 含义 |
|----------|------|
| 油壶（带一滴油） | 机油压力过低 |
| 温度计 / 水波纹 | 水温过高 |
| 发动机形状 | 发动机故障 |
| 蓝色远光符号 | 远光灯已开启（正常提示） |
| 燃油泵 / 油枪 | 燃油不足 |
| 圆圈内「P」 | 驻车制动（手刹）拉起提示 |
| 圆圈内「!」 | 制动系统故障警告 |

:::note[记忆技巧]
蓝色灯 = 远光（正常提示）；红色 / 黄色灯 = 故障 / 危险警告。
:::

## 八、高频情景判断：5 条铁律

**01 让行铁律**

转弯让直行；右方道路来车先行；相对方向行驶时，右转让左转。

**02 高速公路故障处理**

```
双闪 → 靠应急车道停车 → 在车后 150 米外放置警示标志 → 人员撤到护栏外 → 报警
```

**03 轻微事故处理**（无人伤亡，能协商）

先**撤离现场**再协商，切勿堵路。

**04 恶劣天气驾驶**

雨雪结冰路面：制动距离变长、跟车距离加大、降低车速。

**05 信号灯 vs 交警**

有交警 → 听交警；无交警 → 看信号灯；无信号灯 → 看标志标线。

## 九、最后一条原则：安全导向心法

:::important[科目一命题导向]
科目一命题有明确的「安全导向」：

选项中凡是「**减速、停车、让行、观察、确认安全**」的，大概率**正确**；

凡是「**加速、抢行、强行超车、随意变道**」的，大概率**错误**。

数字题和手势题靠背，其余判断题靠这条安全直觉能救回不少分。
:::
